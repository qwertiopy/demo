Advanced Configuration

WEAPONS contains exactly 10 player weapons. Each entry is bullet stats: speed, radiusBlocks, color, damage, maxBounces, spreadOffset, lifetimeMs, explosionRadiusBlocks, detonationTimeMs, explosionDurationMs, explosionDamage, detonatesOnImpact, throwable, throwDistanceMultiplier, throwDeceleration, laser, laserWarmupMs, cooldownMs, and penetrationBlocks.

Explosives: detonationTimeMs = 0 disables the timed fuse. If detonatesOnImpact is true, the projectile detonates when a wall collision would exceed maxBounces. Explosion radius is measured in blocks.

Throwables: set throwable = true. Normal projectile speed is ignored. Throw distance is the shooter-to-aim distance multiplied by throwDistanceMultiplier. throwDeceleration is a constant physical deceleration in blocks/sec². The required initial throw speed and flight duration are calculated automatically so the projectile reaches its target path distance at exactly zero speed.

Lasers: set laser = true. Firing starts a warmup for laserWarmupMs, then resolves an instantaneous beam. cooldownMs applies to every weapon: ordinary projectiles and throwables start cooldown when fired, while lasers start cooldown when the beam fires after warmup. Cooldowns are tracked separately per weapon. Laser aim is locked when the shot is started.

Penetration: penetrationBlocks delays collision actions by that depth into each collider. If a wall or target is thinner than the configured penetration along the projectile's travel direction, the projectile phases through it completely. This applies to ordinary projectiles and laser beams.

Structure grid flags: 0 = empty, 1 = wall, 2 = random enemy, 3 = g-bot, 4 = j-bot, 5 = h-bot.
