Advanced Configuration

WEAPONS contains exactly 10 player weapons. Each entry is bullet stats: speed, radiusBlocks, color, damage, maxBounces, spread, lifetimeMs, explosionRadiusBlocks, detonationTimeMs, explosionDurationMs, explosionDamage, detonatesOnImpact, throwable, throwDistanceMultiplier, throwDeceleration, laser, laserWarmupMs, cooldownMs, penetrationBlocks, and bulletCollision.

Spread: spread is a random total angular cone width in radians. Every shot samples a random offset from -spread/2 to +spread/2, including player bullets, enemy bullets, and lasers.

Explosives: detonationTimeMs = 0 disables the timed fuse. If detonatesOnImpact is true, the projectile detonates when a wall collision would exceed maxBounces. Explosion radius is measured in blocks.

Throwables: set throwable = true. Normal projectile speed is ignored. Throw distance is the shooter-to-aim distance multiplied by throwDistanceMultiplier. throwDeceleration is a constant physical deceleration in blocks/sec². The required initial throw speed and flight duration are calculated automatically so the projectile reaches its target path distance at exactly zero speed. For throwables, maxBounces controls boomerang reversals at the end of each throw leg; wall bounces themselves are unlimited.

Lasers: set laser = true. Firing starts a warmup for laserWarmupMs, then resolves an instantaneous beam. cooldownMs applies to every weapon: ordinary projectiles and throwables start cooldown when fired, while lasers start cooldown when the beam fires after warmup. Cooldowns are tracked separately per weapon. Laser aim is locked when the shot is started. maxBounces also controls laser wall reflections.

Penetration: penetrationBlocks is one total wall-travel budget. Moving bullets subtract their intended substep distance while overlapping walls; enemies never consume penetration and are damaged immediately on overlap. A bouncy bullet that exhausts penetration inside a wall finishes exiting that wall before its next wall collision can bounce. Laser hitscan consumes the same wall-distance budget along its ray.

Projectile collision: set bulletCollision = true to make that projectile physically collide with every other player or enemy projectile on every simulation frame. Only one projectile in a pair needs the flag enabled for the pair to collide. Projectile/projectile contact does not deal damage or consume wall penetration.

Structure grid flags: 0 = empty, 1 = wall, 2 = random enemy, 3 = g-bot, 4 = j-bot, 5 = h-bot.
